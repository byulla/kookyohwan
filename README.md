# 구교환 (求교환)

> 수강신청 정정기간에 **정원이 마감된 교양 과목을 서로 맞바꿀 상대를 찾아 주는 프로그램**
> Java 17 · 표준 API만 사용 · 콘솔 + Swing GUI · CSV 저장

마감된 교양 과목은 누군가와 바꾸는 수밖에 없는데, 상대를 찾으려면 게시판 글을 하나하나 읽고 시간표를 직접 대조해야 한다.
구교환은 교환 요청을 한 곳에 모아 두고, 조건이 맞는 상대를 찾아 **시간표가 겹치는지까지 검사해서** 가능한 상대만 골라 준다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 과목 조회 | 가천대학교 2026학년도 2학기 개설 과목 3,242개. 교과목명·교수명 일부나 학수번호 앞자리로 검색, 빈자리/마감 표시 |
| 시간표 관리 | 요일 x 교시 격자. 과목을 넣을 때 시간이 겹치면 겹치는 과목을 보여 주고 교체 여부를 묻는다 |
| 교환 요청 | 내놓을 과목(내 시간표의 교양) + 희망 과목명(분반 무관)으로 등록 |
| 1:1 매칭 | 내가 내놓는 과목 = 상대가 원하는 과목, 상대가 내놓는 과목 = 내가 원하는 과목인 요청을 찾는다 |
| 세 명 교환 | A -> B -> C -> A로 과목이 도는 교환. 대기 요청을 깊이 우선 탐색(DFS)으로 따라가 찾는다 (GUI) |
| 겹침 검사 | 받을 과목이 내 시간표와 겹치거나, 상대가 내 과목을 받았을 때 상대 시간표와 겹치면 사유와 함께 제외 |
| 교환 확정 | 가능한 상대를 골라 확정하면 시간표의 과목이 맞바뀌고 요청이 매칭완료가 된다 (GUI) |
| 저장·복원 | 학생 시간표와 요청을 CSV 파일에 저장하고 다음 실행 때 그대로 복원 |

### 적용 규칙

- 교환 대상은 **교양 과목만**. 전공은 시간표에는 넣되 교환 요청은 할 수 없다
- 겹침 검사 때 **내놓는 과목은 비교에서 뺀다** (내놓으면 그 자리가 비므로)
- 한 학기 **최대 18학점**. 넘게 되는 추가·교체·교환은 거절하거나 제외한다
- 같은 과목은 한 분반만 들을 수 있다 (중복 수강 금지)
- 시간표는 '편집 중'으로 시작해 지금 듣는 과목을 옮겨 적고 확정한다. 확정한 뒤에는 빈자리가 있는 과목만 바로 수강신청할 수 있고, **마감된 과목은 교환으로만** 얻는다
- 희망하던 과목을 직접 수강신청하면 그 요청은 자동으로 취소된다
- 자기 자신의 요청끼리는 매칭하지 않는다

## 실행 방법

| 항목 | 내용 |
|---|---|
| Java | JDK 17 이상 (`java -version`으로 확인). 외부 라이브러리 없음 |
| 작업 폴더 | `data/courses.csv`처럼 상대 경로로 읽으므로 **프로젝트 루트(`kookyohwan/`)에서 실행**. IDE는 Working directory를 루트로 |
| 문자 인코딩 | 소스·데이터 모두 UTF-8. 컴파일 시 `-encoding UTF-8` 필수 |
| 터미널 폭 | 콘솔은 100칸 이상 권장 |

Mac / Linux

```bash
cd kookyohwan
find src -name "*.java" > sources.txt
javac -encoding UTF-8 -d out @sources.txt

java -cp out kookyohwan.GuiMain     # GUI
java -cp out kookyohwan.Main        # 콘솔
```

Windows (cmd)

```bat
cd kookyohwan
dir /s /b src\*.java > sources.txt
javac -encoding UTF-8 -d out @sources.txt

java -cp out kookyohwan.GuiMain
chcp 65001
java -Dfile.encoding=UTF-8 -cp out kookyohwan.Main
```

시작하면 학번을 묻는다. **테스트 학번은 `202633781`(조혜라)** 이고 입력 칸에도 적혀 있다.
등록되지 않은 학번을 넣으면 이름을 받아 빈 시간표로 시작한다.

다른 데이터 폴더로 실행하려면 폴더 이름을 인자로 준다.

```bash
java -cp out kookyohwan.Main data-ac8
java -cp out kookyohwan.GuiMain data-swap3
```

## 화면 구성

### GUI (Swing)

| 탭 | 내용 |
|---|---|
| 내 시간표 | 시간표 격자. 과목 블록을 누르면 뺄 수 있다. 편집 중일 때만 [확정] 버튼이 보인다 |
| 과목 목록 | 검색·필터 표. 버튼 하나가 상황에 따라 바뀐다: 내 시간표에 넣기 / 수강신청 / 이 과목으로 교환 요청 |
| 교환 | 왼쪽에 내 대기 요청과 새 요청 등록, 오른쪽에 고른 요청과 교환할 수 있는 상대 카드. 카드의 [교환 확정]으로 바로 확정 |
| 전체 요청 | 모든 요청 목록. 내 과목을 희망하는 요청이 맨 위에 색칠되어 나오고, 줄에 마우스를 올리면 교환할 방법을 알려 준다 |

- 교환 탭에서는 둘이서 하는 교환과 세 명이 함께 하는 교환이 같은 목록에 나온다
- 내 시간표와 겹치는 과목만 문제라면 [빼고 교환]으로 그 과목을 빼고 교환할 수 있다
- 저장 버튼은 없다. 바뀔 때마다 자동으로 저장한다
- 사용자 전환은 오른쪽 위 버튼

### 콘솔

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 과목 목록 보기 | 교과목명 일부나 학수번호 앞자리로 검색 (최대 30줄). 과목마다 빈자리 또는 마감 표시 |
| 2 | 내 시간표 보기 / 과목 추가 | 요일 x 교시 격자. 편집 중: 학수번호로 넣고 `저장`으로 확정. 확정 후: 빈자리 있는 과목만 수강신청. `-학수번호`로 과목 빼기 |
| 3 | 교환 요청 등록 | 내놓을 과목 번호 + 희망 과목명 (학수번호를 넣으면 과목명으로 변환) |
| 4 | 교환 요청 목록 보기 | 전체 요청과 상태. 내 요청은 `<- 내 요청` 표시 |
| 5 | 매칭 실행 | 내 대기 요청에 맞는 상대를 `[가능]`/`[제외]`와 사유로 출력 |
| 9 | 사용자 전환 | 저장한 뒤 학번을 다시 입력 |
| 0 | 저장하고 종료 | `students.csv`, `requests.csv`를 다시 쓰고 종료 |

하위 입력에서 빈 줄(Enter)을 넣으면 메뉴로 돌아간다. 잘못된 입력은 `[오류]`나 `[거절]`을 내고 다시 받는다.
콘솔의 매칭은 조회 전용이다(요청 상태를 바꾸지 않는다). 교환 확정과 세 명 교환은 GUI에서 한다.

## 프로그램 구조

```
kookyohwan/
├── README.md
├── data/                준비 데이터 + 저장 파일 (학생 47명, 요청 161건)
├── data-ac8/            콘솔 시연용 데이터 (학생 7명, 요청 8건)
├── data-swap3/          세 명 교환 시험용 작은 데이터 (학번 202630001)
├── test/                테스트 5개 (JUnit 없이 main으로 실행)
└── src/kookyohwan/
    ├── Main.java        콘솔 진입점: 복원 -> 학번 입력 -> 메뉴 -> 저장
    ├── GuiMain.java     GUI 진입점
    ├── model/           데이터와 자기 상태에 대한 판정
    ├── service/         보관·조회·등록·매칭·교환 확정
    ├── storage/         CSV 읽기·쓰기
    ├── ui/              콘솔 화면
    └── gui/             Swing 화면
```

| 패키지 | 클래스 |
|---|---|
| `model` | `Day`, `TimeSlot`, `CourseType`, `Course`, `Timetable`, `Student`, `RequestStatus`, `SwapRequest`, `MatchVerdict`, `MatchResult`, `CycleMatch` |
| `service` | `Repository<K, V>`, `CourseCatalog`, `StudentRegistry`, `RequestBoard`, `MatchService`, `ExchangeService`, `EnrollmentService` |
| `storage` | `Storage`(인터페이스), `FileStorage` |
| `ui` | `ConsoleUI`, `TimetableGrid`, `TextUtil` |
| `gui` | `MainPanel`, `TimetablePanel`, `TimetableCanvas`, `CoursePanel`, `ExchangePanel`, `RequestPanel`, `LoginGate`, `Session`, `Theme` 등 |

### 설계 원칙

- **의존 방향은 한쪽으로만**: `ui`·`gui` -> `service` -> `model`, `storage` -> `model`. 저장 구현체(`FileStorage`)는 진입점만 안다
- **콘솔과 GUI가 같은 `service`를 쓴다.** 규칙·겹침·매칭을 화면마다 다시 만들지 않았다
- **겹침 판정은 `Timetable.findConflicts` 한 곳.** 시간표 추가, 매칭(내 쪽), 매칭(상대 쪽), 교환 확정이 모두 이 메소드를 부른다
- **상태를 바꾸는 곳을 정해 두었다**: 시간표는 `Timetable`, 요청 목록은 `RequestBoard`, 학생 목록은 `StudentRegistry`, 파일은 `FileStorage`. `MatchService`는 조회만 한다
- **교환 확정은 `ExchangeService` 한 곳.** 확정 직전에 매칭을 다시 돌려 가능할 때만 반영하고, 중간에 실패하면 되돌린다

### 사용한 자바 기능

| 기능 | 쓰인 곳 |
|---|---|
| enum | 요일(`Day`), 과목 구분(`CourseType`), 요청 상태(`RequestStatus`), 판정(`MatchVerdict`) |
| 제네릭 | `Repository<K, V>`를 과목·학생·요청 보관소가 공유 |
| 컬렉션 | `List`, `LinkedHashMap`(입력 순서 유지), `EnumMap<Day, Course[]>`(시간표 격자) |
| `Optional` | '없음'을 `null` 대신 `Optional.empty()`로 (`find`, `findConflict`, `resolveName`) |
| 인터페이스 | `Storage` <- `FileStorage`. 저장 방식이 바뀌어도 `service`는 그대로 |
| 예외 처리 | 잘못된 입력·깨진 파일에도 죽지 않고 안내 후 계속 |
| 재귀 (DFS) | `MatchService.matchCycles`의 세 명 교환 탐색 |
| Swing | GUI 화면 전체 |

## 데이터 파일

UTF-8, 첫 줄은 헤더, 구분자는 쉼표. 한 칸에 값이 여러 개면 세미콜론(`;`). 값 안에 쉼표가 있으면 큰따옴표로 감싼다.

| 파일 | 형식 | 예 | 읽기·쓰기 |
|---|---|---|---|
| `courses.csv` | 코드,과목명,분반,구분,시간,교수,강의실,학점,정원,수강인원 | `08306001,운영체제,001,MAJOR,목4-5;금3,오기욱,AI관-209,3,60,60` | 읽기 전용. 없으면 안내 후 종료 |
| `students.csv` | 학번,이름,과목코드,시간표상태 | `202612346,백찬샘,07251001;05306001,CONFIRMED` | 저장·복원. 없으면 빈 상태로 시작 |
| `requests.csv` | 번호,학번,내놓는과목코드,희망과목명,상태 | `1,202612346,11393006,프랑스어1,WAITING` | 저장·복원. 없으면 빈 상태로 시작 |

- 코드 = 학수번호 8자리, 분반 = 학수번호 끝 3자리, 과목명 = 교과목명 그대로
- 시간 `월3-4` = 월요일 3교시부터 4교시까지, `금3` = 금요일 3교시
- 구분: `MAJOR`(전공) / `GENERAL`(교양) / `TEACHING`(교직) / `MILITARY`(군사)
- 상태: `WAITING`(대기) / `MATCHED`(매칭완료) / `CANCELLED`(취소). 시간표상태: `EDITING`(편집 중) / `CONFIRMED`(확정)
- 빈자리 = 정원 - (수강인원 + 이 프로그램에 등록된 학생 중 그 과목을 듣는 사람 수)
- 과목 목록은 학교 시간표를 변환한 것이다. **정원은 실제 값이고 수강인원은 시연용으로 만든 값**이다
- 형식이 틀린 줄이 있으면 파일명과 줄 번호를 알려 주고 종료한다 (일부만 읽고 계속하면 저장할 때 그 줄이 사라지므로)

## 테스트

JUnit 없이 `main`으로 실행한다. 실패하면 어떤 경우인지와 씨앗 번호가 출력된다.

```bash
javac -encoding UTF-8 -cp out -d out test/*.java
java -cp out ConflictTest
java -cp out ScenarioTest
java -cp out EdgeCaseTest
java -cp out CycleTest
java -cp out WeirdTest
```

| 테스트 | 개수 | 내용 |
|---|---:|---|
| `ConflictTest` | 189 | 겹침·학점·중복 수강·교환 확정·세 명 교환 규칙 |
| `ScenarioTest` | 108 | 단위 테스트 + 콘솔 시나리오 (`data-ac8` 사본 사용) |
| `EdgeCaseTest` | 2,191 | 깨진 파일, 엉뚱한 입력, 입력 끊김, 무작위 입력 |
| `CycleTest` | 50,000 | 세 명 교환 무작위 검증. DFS 결과를 전수 조사와 비교하고 확정 뒤 시간표가 어긋나지 않는지 확인 |
| `WeirdTest` | 100,000 | 깨진 글자, 망가진 CSV, 터무니없이 큰 숫자, 아무렇게나 두드린 콘솔 |

테스트는 데이터 폴더의 사본이나 임시 폴더를 쓰므로 `data/`를 바꾸지 않는다.
